# EventPix — AI Youth Festa pitch deck

A [Slidev](https://sli.dev/) deck pitching **EventPix**, an AI-powered event-photo discovery
and monetization platform for the Laos market. Runs about 8 minutes.

```bash
pnpm install
pnpm dev      # http://localhost:3030
```

- Press `O` for the slide overview, `F` for fullscreen.
- Presenter mode with notes and the countdown timer: http://localhost:3030/presenter
- `pnpm build` produces a static site in `dist/`.
- `pnpm add -D playwright-chromium && pnpm export` produces a PDF backup.
